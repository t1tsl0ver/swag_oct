Это базовая нейросеть для дальнейших сравнений на тех же фолдах. Все пять фолдов завершились раньше лимита 20 эпох: лучшая эпоха была между 7 и 12, затем пять эпох подряд ROC AUC не улучшался. Для предсказаний использованы веса лучшей эпохи каждого фолда. Public score близок к OOF, но одно сравнение не доказывает точность протокола для будущих моделей. Лучшая эпоха выбрана по той же валидационной части, на которой измерен AUC, поэтому оценка может быть немного оптимистичной; дальнейшие изменения проверять одинаковым протоколом.
