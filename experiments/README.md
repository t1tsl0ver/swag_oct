# Эксперименты

Здесь будут записи о проведённых опытах. Для каждого содержательного эксперимента создавайте отдельный Markdown-файл с датой и коротким названием.

Записывайте: гипотезу; использованные данные и разбиение; seed; метрику; параметры и версию кода; измеренный результат; вывод и следующий шаг. Если была отправка на Kaggle, добавляйте ID отправки и фактический результат после его появления.

Первичный интерактивный обзор данных можно пересоздать из корня репозитория:

```powershell
.\.venv\Scripts\python.exe src\swag_oct\visualization\overview.py
```

Отчёт появится в `experiments/data_overview.html` и откроется в браузере без подключения к интернету.
