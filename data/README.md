# Данные

Источник: [Kaggle Playground Series S6E10](https://www.kaggle.com/competitions/playground-series-s6e10/data).

Файлы соревнования: `train.csv`, `test.csv`, `sample_submission.csv`. Они лежат в этой папке локально и исключены из Git. Исходные файлы не изменять.

Повторная загрузка из корня репозитория после авторизации Kaggle:

```powershell
.\.venv\Scripts\kaggle.exe competitions download playground-series-s6e10 -p data --unzip
```

Если понадобятся внешние данные, указывать здесь их источник, версию и назначение.
