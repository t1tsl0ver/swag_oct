# Predicting Airline Satisfaction — нейросетевой конвейер

Данные соревнования лежат локально в `data/`. Код разделён на папки `preprocessing/`, `neural_network/`, `validation/`, `training/`, `submission/` и `visualization/` внутри `src/swag_oct/`.

## Запуск в PowerShell

Откройте терминал **в корне этого репозитория**. После создания `.venv` установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Короткая проверка конвейера на части строк без создания submission:

```powershell
.\.venv\Scripts\python.exe train.py --smoke
```

Полный запуск с пятью фолдами:

```powershell
.\.venv\Scripts\python.exe train.py
```

В консоли и файле `experiments/run_*.log` видны прогресс батчей, loss, ROC AUC каждой эпохи и приблизительное оставшееся время при максимальном числе эпох. Ранняя остановка может завершить запуск раньше. Настройки доступны через `--help`, например `--epochs 30 --batch-size 2048`.

После полного успешного запуска файл `submissions/submission.csv` готов для загрузки на Kaggle. Новый успешный запуск заменяет предыдущий файл; при ошибке прежний остаётся. Локальная оценка и настройки записываются в `experiments/run_*.md`, OOF и test-прогнозы — в локальный `experiments/run_*.npz`. После получения public score добавьте его к соответствующей записи эксперимента.

Преобразование категорий фиксировано и общее для фолдов; медианы и масштабы числовых столбцов рассчитываются только на обучающей части каждого фолда. Нейросеть обучается отдельно для каждого фолда. Аугментация данных пока не включена.
