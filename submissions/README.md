# Отправка на Kaggle

После успешного полного обучения здесь появляется `submission.csv` с колонками `id,satisfaction`. Каждый новый полный запуск конвейера проверяет файл и заменяет предыдущий `submission.csv`; папка хранит только актуальную отправку. CSV исключён из Git.

Результат публичного лидерборда и локальный OOF ROC AUC записываются в заметку соответствующего запуска в `experiments/` после получения оценки Kaggle.
